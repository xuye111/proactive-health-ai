# ADR-0002：记录与趋势合并为一个一级入口

- 状态：已采纳
- 日期：2026-09-19
- 相关文件：`src/pages/Record.tsx`

## 背景

记录（今天：行动/数据/目标达成）与趋势（长期：图表/判断依据）都是数据视图，拆成两个底部 tab 会让导航变成「功能清单」而不是「用户任务」。方案原本允许趋势作为记录的二级页面。

## 决策

合并为一个入口「记录」，页内用「今天 / 趋势」分段切换，两个视图共用同一份数据与组件。

## 备选方案与代价

**A. 保持两个 tab**：趋势更容易被发现。代价是底部 5 个入口里有两个是同类对象，用户要在两个地方找同一件事。
**B. 只保留趋势，砍掉今日数据**：长期视图更纯粹，但用户失去了「今天录了什么」的入口，闭环断裂。

## 什么情况下会推翻

若数据表明「趋势」分段的打开率长期低于 10%，说明合并后趋势被埋没，应重新评估独立入口。
