# ADR-0003：助手页同时提供主动与自主两条路径

- 状态：早期通用健康原型已采纳。现行痛风随访见[架构说明](../architecture.md#默认页面与数据流)。
- 日期：2026-09-19
- 相关文件：`src/pages/Agent.tsx`

## 背景

产品的核心是主动，但「只能等 AI 开口」是另一个极端：用户有疑问时无处可问。同时，方案 §6 明确要求不能做成普通 ChatGPT 对话框——难点在于「给入口」和「不变成通用问答」之间的平衡。

## 决策

两条路径共存且共用同一份上下文：**主动**（发现→追问→更新判断）与**你发起**（随时提问）。问答案的回答必须引用当日数据、已了解的状态与健康档案，并标注输出分级。规则答不了的问题给出诚实的兜底，而不是编答案。

## 备选方案与代价

**A. 只做主动**：产品纯粹，但用户想问「今天适合运动吗」时只能等 AI 来问。
**B. 做成通用聊天框**：实现最简单，但回答会退化成通用建议，且丢掉「已经了解你」这个核心体验。

## 什么情况下会推翻

当开放性问题占比超过 30% 且兜底率居高不下时，说明规则答不了真实需求，应接入 LLM 而不是继续扩关键词表。
