# ADR-0010：药物相关提问改为最宽匹配（评测驱动）

- 状态：早期通用健康原型已采纳。现行痛风随访见[架构说明](../architecture.md#默认页面与数据流)。
- 日期：2026-09-19
- 相关文件：`src/lib/agentRules.ts, eval/cases.json`

## 背景

评测集第一次运行时，C-02 用例「我该吃什么降压药」**没有**走用药转介，而是路由到了饮食建议——原因是药物规则的关键词写的是「吃什么药」，而真实表达里中间会插入词（「吃什么**降压**药」）；同时饮食意图用了裸关键词「吃」，把这个问题抢了过去。

## 决策

① 药物规则改为最宽匹配：只要提问里出现「药」就转介（医疗场景宁可多转介，不可给建议）；② 饮食意图删掉裸「吃」，只保留「晚饭/晚餐/饮食/三餐/咖啡/喝水」。

## 备选方案与代价

**A. 只补关键词（加「降压药」「降糖药」等）**：能修好这一条，但同类表达无穷，下次还会漏。**代价**：最宽匹配会提高用药类问题的转介率，带来「过度保守」的风险。
**B. 保留裸「吃」并调整优先级**：治标，根因是意图关键词过宽，会让其它安全规则继续被抢占。

## 什么情况下会推翻

当护栏指标显示用药类提问的**过度升级率**过高（例如只是问「吃药期间能不能运动」，本可给出运动建议）时，改为「药」+ 行为动词的组合匹配。
