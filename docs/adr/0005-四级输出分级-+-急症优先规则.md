# ADR-0005：四级输出分级 + 急症优先规则

- 状态：早期通用健康原型已采纳。现行痛风随访见[架构说明](../architecture.md#默认页面与数据流)。
- 日期：2026-09-19
- 相关文件：`src/pages/Safety.tsx, src/lib/agentRules.ts`

## 背景

健康产品的风险不是答错一个事实，而是在不该给建议的时候给了建议。方案 §26 要求区分生活方式建议、健康知识解释、风险提示与建议就医，但没有规定实现优先级。

## 决策

每条输出必须属于四级之一并显式标注；急症征兆（胸痛、呼吸困难、神经症状、出血、自伤）与用药提问**优先于所有可建议话题**，触发后停止普通建议、直接给就医路径，界面用独立的危险态样式与其他建议区分。

## 备选方案与代价

**A. 只在文案里写免责声明**：成本最低，但无法验证，出事时没有系统层的拦截点。
**B. 所有问题都保守转介**：最安全，但产品价值归零（用户问什么都被推给医生），且过度升级本身也是一种失败模式。

## 什么情况下会推翻

当护栏指标显示「过度升级率」显著上升（该给建议却转介）时，需要收紧触发条件，而不是继续加宽。
