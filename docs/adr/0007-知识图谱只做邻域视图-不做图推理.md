# ADR-0007：知识图谱只做邻域视图，不做图推理

- 状态：已采纳
- 日期：2026-09-19
- 相关文件：`src/pages/profile/Graph.tsx`

## 背景

方案 §25 明确把「完整知识图谱」列入 MVP 不做清单，但实体与关系本身是有价值的表达：它能说明「咖啡因 → 推迟入睡时点 → 影响睡眠时长 → 触发睡眠下降信号」这条解释链是怎么来的。

## 决策

图谱页只做**局部邻域视图**：选中一个实体，展示它的直接关系（12 个实体 / 12 条关系），点节点可继续走。页面明确标注不做完整图推理与路径检索。

## 备选方案与代价

**A. 做一个看起来完整的力导向大图**：视觉冲击强，但既没有推理能力也没有交互价值，属于演示型假功能。
**B. 完全不做图谱页**：省事，但丢掉「判断依据可追溯」这一层表达。

## 什么情况下会推翻

当需要回答「为什么这两个结论相关」这类解释链问题时，第四阶段接入路径检索（BFS 有限深度），届时本视图成为其入口。
